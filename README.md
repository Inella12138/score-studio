# 简谱工坊

Windows 离线录谱、实时简谱预览与 AutoHotkey v2 演奏脚本生成工具。

## 桌面版与共享曲库

完整解压桌面发行包，双击 **ScoreStudio.exe**。它会在本机启动编辑器并以独立浏览器窗口打开，不需要安装 Node.js。启动器窗口可最小化，关闭它会停止本地服务，请先保存曲谱。编辑器依赖本机 Edge / Chrome；没有时会用默认浏览器打开。EXE 是启动器，需与整包文件一起保留，不是单文件应用。

曲谱保存在 **EXE 同目录的 `scores` 文件夹**。请将应用解压到有写入权限的位置，例如桌面或 D 盘，不建议 Program Files。

- **保存到曲库**：把当前项目写入 `scores`，仍保留草稿自动保存。已有同名曲谱请先从曲库打开再编辑；避免意外覆盖。
- **曲库**：查看并打开本地项目。原来的“打开项目”可以导入别处的 JSON，再保存进曲库。
- **更新曲库**：从公开的 `Inella12138/score-studio` 仓库下载新曲谱，不需要 GitHub 账号，也不用安装 Git。本地未上传修改会保留；双方同名修改时，远程副本保存到 `.local/conflicts`，不会直接覆盖。
- **上传曲谱**：检查 `scores` 中新增和修改的曲谱，展示待上传清单，点击确认后提交到公开仓库。不会上传浏览器未保存的草稿，不会上传临时文件或凭据。上传后任何人可查看。

仅上传者需要安装 Git for Windows（含 Git Credential Manager），在曲库窗口点“GitHub 登录”通过浏览器授权。账号需要该仓库的写入权限；伙伴免登录更新不受影响。认证保存在系统凭据管理器，应用页面和项目文件不保存令牌。GitHub 与 GitLab 按域名分别认证，不需要更改公司账号。

建议每次开工先“更新曲库”，编辑后“保存到曲库”，完成后“上传曲谱”。远程在预览后发生变化会拒绝上传，需要重新更新核对。重命名会视作新增，删除不会自动同步，以避免丢失曲谱；冲突需比较副本后另存新名称。若想同步删除，请由维护者在仓库处理。公开 GitHub 有匿名请求频率限制，网络或频率错误时稍后重试，本地编辑照常可用。

应用更新和曲库更新是分开的：曲库按钮只下载 JSON，不下载或执行远程程序；应用版本更新请下载新的桌面包。换设备或更新应用时，请先备份整个 `scores` 和 `.local` 文件夹。浏览器旧版 `file://` 草稿与桌面版的本机地址不同，旧草稿请先导出 JSON，再在桌面版打开。

首次启动会检查常见安装位置的 AutoHotkey v2；未检测到时可选择打开随包离线安装界面或跳过。只有演奏导出的脚本才需要 AHK。便携版或自定义安装路径可能未被检测到，已能运行 v2 脚本时可跳过安装。

### 从源码打包

Windows 需要 Node.js 22 和 .NET Framework 4.x 编译器。执行 `powershell -NoProfile -File desktop/build.ps1 -Package`，生成 EXE 和包含运行环境、安装包及曲谱的 ZIP。ZIP 不包括 Git 认证、本机同步记录、测试依赖、个人草稿。测试：`node --test core.test.js ui.test.js mode.test.js desktop/*.test.js`（页面测试需要先安装下文的 jsdom）。

附带 Node.js 的完整授权见发行包 `bin/LICENSE-node.txt`（源码副本在 `desktop/LICENSE-node.txt`）。附带原版 AutoHotkey ZIP 中保留其授权；对应 2.0.26 源码可从官方 AutoHotkey/AutoHotkey 仓库的 v2.0.26 标签获取。

双击 `index.html`，即可离线使用。无需安装依赖或启动服务。编辑器左侧输入，右侧实时显示简谱；声部之间按拍对齐，自动检查每个小节的长度。

## 首次在 Windows 使用

完整解压应用后，双击“启动编辑器.cmd”打开页面。编辑和保存曲谱无需 AutoHotkey 或 Node.js。

需要播放导出的脚本时，若尚未安装 AutoHotkey v2，可双击“首次安装AutoHotkey.cmd”。输入 Y 确认后，助手校验并解压附带的本机 AutoHotkey 2.0.26 ZIP，打开原版安装界面，由你选择安装或取消；不进行静默安装、不自动改系统默认程序、不修改已有安装。已有 v2 可跳过。

安装通常会处理 `.ahk` 关联；如果双击仍用其他程序打开，请通过 Windows“打开方式”选择已安装的 AutoHotkey。ZIP 单纯解压不会注册默认打开方式。若 PowerShell 策略阻止助手，不需要修改策略：手动完整解压 `installers/AutoHotkey_2.0.26.zip` 并运行其中的 `Install.cmd` 即可。

原版授权文本保留于附带 ZIP。该版本是用户提供的本地副本，不代表最新版；校验值用于确认副本一致性。助手的临时解压位于本应用 `runtime`，每次使用独立目录，不覆盖已有文件；完成安装后不依赖该目录。分发包不包含浏览器草稿或个人曲谱，复制设备前请另外保存项目 JSON。

## 使用

1. 设置 BPM、拍号和键位。BPM 始终以四分音符为一拍；6/8 的默认小节长度为 3 拍。
2. 按声部输入代码，用 `|` 分隔小节，换行只用于排版。
   声部标题栏的 ↑ / ↓ 可调整声部顺序；谱面、导出列表和保存的项目会同步更新，声部名称、ID 与音符内容不变。
   每个声部下方独立显示自身小节总数和光标所在小节，不包含为其他声部补出的空位。输入末尾小节线后，光标位置会提示下一小节；空白声部显示 0 小节、当前第 1 小节。
   也可以连续录入后点击声部右上角“自动分小节”，按当前拍号和特殊小节长度重新插入小节线，每小节一行。会重算已有小节线，不自动补休止或改动其他声部；最后一小节不足时保留提示。普通长音跨小节自动拆分并连接延音，休止自动拆分。三连音和装饰音若跨小节则提示手动调整，原文保持不变。“撤销分小节”可恢复最近一次操作，后续已有新编辑时不会覆盖它。变速表仍按原小节编号生效，重新划分后请核对对应位置。
3. 在“小节与键位设置”中添加曲速和节拍规则，每条规则可选“仅此小节”“指定范围”“从此小节起”。曲速默认从此小节起，节拍默认仅此小节；节拍可以填 `2/4`，也可切换成自定义长度（四分音符拍数，例如 `3/2`）。
4. 导出时选择全部声部或部分声部，以及点按或按住模式。各声部即使单独导出，也保留完整的曲首休止与速度时间线。
5. 在安装 AutoHotkey v2 的电脑运行 `.ahk`，让钢琴窗口获得焦点，按 `Ctrl+Enter` 开始。`Ctrl+Win+P` 暂停或继续，`Ctrl+Win+Esc` 停止并释放琴键。停止后可重新开始。

手动开始默认显示 3 秒倒计时，再从曲首播放；导出窗口可设置 0～60 秒延迟。倒计时期间也可暂停或停止。定时开始按预设时刻直接播放，不叠加手动延迟。曲谱原有的开头休止仍保留。

导出新版脚本后，运行时按 `Ctrl+Win+T` 呼出定时面板，无需因每次开演时间不同而重新导出。每次打开预填本机当前日期时间，提供“当前时间 +30秒 / +1分钟 / +5分钟”按钮，每次点击都从点击时的当前时间计算。可微调后点击“准备”，面板隐藏，再切回钢琴窗口。目标时间必须晚于当前时间。面板显示已有定时及剩余秒数；再次打开时输入框仍预填当前时间，未重新准备不会更改原定时。关闭或 Esc 只隐藏面板，“取消定时”按钮或 `Ctrl+Win+Esc` 才取消等待。手动开始会取消原定时；演奏中需先停止再打开面板。定时触发会隐藏面板，不自动切换或抢占钢琴窗口焦点，不提供跨机器校时。

按住模式导出支持“重复音松键间隔”（默认 30ms，可设 0～1000ms）和“前音最低保留比例”（默认 80%，可设 1～100%）。同键相邻重复时，提前松开 `min(设置间隔, 前音时长 × (1 - 保留比例))`，后音仍按原拍点开始。和弦只提前释放重复键；显式延音不在连接处松开。两项参数随项目与草稿保存；间隔 0 或保留比例 100% 可关闭。30ms 是兼容性试验初值，不是乐理标准，极短间隔仍可能受软件与系统调度影响。

可额外启用本地时间定时开始。脚本打开时若已超过预设时间，会立即开始。程序不自动校时，不保证跨机器或实际音频输出精确同步。导出的脚本启动时会自动申请管理员权限，以便向管理员权限的钢琴软件发送按键；取消权限请求会退出脚本。

## 曲速与节拍规则

定时面板另提供未来两分钟的 24 个绝对时间节点，秒数固定为 00、05、10……55。列表每秒刷新，移除过期节点并补上新节点；点击只填写日期时间，仍需点击“准备”确认。选定时间不会随列表刷新改变。跨午夜的节点显示月日，日期时间框保留完整日期。两台电脑选择相同时间节点即可约定开演，但仍需自行校时；原来的相对时间按钮保留。新版功能需先重新导出脚本一次。

### 按小节切换点按／按住

导出窗口上方选择默认模式，再在“小节模式例外”中给单小节、指定范围（含首尾）或从某小节起指定另一种模式。例外作用于本次导出的全部选中声部，包含临时并行分支；设置和默认模式随项目保存，不会操作软件的乐器切换。

双人交接示例：A 默认选按住模式，把第 1～4 小节设为点按，第 5 小节显式休止以手动换乐器，第 6 小节加入；B 全程按住，前 4 小节显式休止。两份脚本保留完整曲首时间线。切换不增加等待时间，需自行在谱中安排休止。

模式范围遵循相同覆盖规则：临时范围覆盖持续设置，范围结束后恢复；完全包含时较小范围优先，交叉范围报错。装饰音简化、换气及重复音松键只在相应按住小节应用。模式边界会结束旧的持续按键；跨模式延音在新模式重新触发，而同模式延音保持不变。旧项目没有模式规则时仍按单一默认模式导出。

| 生效方式 | 行为 |
|---|---|
| 仅此小节 | 只影响起始小节，下一小节恢复届时有效的设置 |
| 指定范围 | 起始至结束小节都包含，结束后的下一小节自动恢复 |
| 从此小节起 | 持续生效，直到下一条持续规则改变基准值 |

例如全曲默认 `4/4`、BPM 74：设置第 20～40 小节为 `2/4`，第 25 小节 BPM 68。第 25 小节显示 `♩=68`，第 26 小节显示恢复后的 `♩=74`。曲速只有实际值发生变化才重复标注，曲首也会显示初始值。特殊小节在谱面显示醒目的实际拍数，例如 `2 拍`；不额外显示 `2/4` 拍号标记，设置中的拍号仍决定长度及短音分组。

临时规则覆盖持续规则；完全包含的临时范围中，较小范围优先，单小节可覆盖所在范围。临时规则结束后恢复当时有效的持续基准；即使期间新增了持续规则，也会使用更新后的基准。规则先后排列不影响结果。相同范围重复或交叉但不完全包含的范围会报错，避免不明确的覆盖关系。

拍号变化同步影响每小节长度、自动分小节、谱面短音分组与导出的播放时间。BPM 始终以四分音符为一拍。自定义拍数只改变长度，不改变当前拍号。旧项目自动保持原语义：旧曲速规则持续生效，旧特殊拍数只影响一个小节。

## 输入语法

### 整小节临时并行

一个声部里的某小节可临时拆成 2～8 条分支，不必新增整首声部。用大括号包住整小节，`&` 分隔：

```text
1 2 3 4 |
{ 1= 3= & 19 59 39 59 } |
5 6 7 1
```

分支在该小节开头同时开始，各自独立填满小节，休止用 `0` 显式填写。该例的两条分支各 4 拍，小节本身只占 4 拍，不是相加。各分支可包含和弦、倚音、三连音、延音和共用时值分组，例如 `{ {12345671}- & 19=== }`。每条分支都按当前特殊拍号、曲速计算；点按同刻同音合并，按住同键重叠报冲突。

谱面只在该小节上下显示分支；同行其他小节会留出对齐空间，不创建额外音轨。导出勾选的是整个声部，包含它所有临时分支。暂不支持半小节并行或嵌套并行。延音按分支顺序连接：分支 1 可与前后普通小节连接，连续并行小节中相同编号分支也可连接；新增分支没有前音，消失的分支不会自动接到其他分支。并行块外的小节边界换气符归于分支 1；其他分支要换气，请在各自末音后标记。

自动分小节会保留并行块并检查各分支拍数。并行块与前后普通内容必须用 `|` 分隔；前面普通段落可以重新分小节，但必须恰好结束于小节边界。并行块不能拆开或自动补齐。`{1234}--` 的旧用法不变：没有 `&` 时仍是共用时值分组。

换气标记使用反引号，放在音符或和弦后，例如 ``1` 2``、``[135]=` 2=``。按住模式按导出设置的松键间隔和最低保留比例提前释放该音全部琴键，即使后音不同也生效，不移动后音拍点。点按模式忽略换气；谱面显示换气记号。三连音整组后写标记时只在末音换气。延音链需在最后一个续音后标记；换气后不能继续用 `~` 延续同音，否则报错。自动分小节会把跨小节长音的换气保留在最后一段。

| 输入 | 含义 |
|---|---|
| `19 1 10` | 低、中、高八度的 do；低音附加 9，高音附加 0 |
| `1 1- 1--` | 一拍、半拍、四分之一拍 |
| `{12345671}-` | 连续八个八分音符，只在组尾写一次 `-` |
| `{1234}--` | 连续四个十六分音符 |
| `{[135] 2 3 4}-` | 和弦与单音可以一起使用共用时值 |
| `1= 1== 1===` | 两拍、三拍、四拍 |
| `1. 1-.` | 一拍半、四分之三拍；支持双附点 |
| `0 0=` | 休止一拍、两拍 |
| `[135]` | 和弦；`[193959]` 是低八度和弦 |
| `(123)` | 三个音均分一拍，`(123)=` 均分两拍 |
| `2'` | 波浪音 232，默认间隔 40ms；7 的上邻音是下一八度的 1 |
| `2'(35)` | 指定波浪音间隔为 35ms |
| `<2>3` | 前倚音：先弹 2，默认 40ms 后弹主音 3，总共仍占一拍 |
| `<2>(30)3-` | 倚音间隔 30ms，倚音与主音共占半拍 |
| `<23>5` | 多个前倚音依次弹奏，最后到主音 5 |
| `[531];(40)` | 按所写顺序弹琶音，间隔 40ms |
| `2'-`、`[531];=` | 装饰音与时值可以组合 |
| `1=== \| ~1===` | 后一小节延续同音，不重新触发 |
| `[135]=== \| ~[531]===` | 整组相同音高的和弦延音，顺序可以不同 |
| `[2 79 59 29];= \| ~29=` | 琶音最后一个音延续到下一小节；示例需使用两拍小节 |

`-` 与 `=` 不在同一音符上混用。三连音内可写普通单音、休止、和弦、同音延音及前倚音。例如 `(10~1010)`：三个高音 1 均分一拍，前两个连成延音，第三个重新触发；也支持 `([135]~[531]~[153])` 整组同音和弦延音。`~` 写在括号内后一个音前，不能用于休止或不同音高。

`(4050<40>50)` 表示三个主音为高音 4、高音 5、高音 5，第三个主音前有高音 4 的倚音；默认间隔 40ms，只占第三个音的时值，不改变整组时值。三个位置均可有倚音，也可写多个倚音或接主和弦，例如 `(1 <23>(25)[135] 4)`。按住模式仍忽略倚音只保留主音；间隔超出所在三分之一时值时，点按模式阻止导出。倚音不能放在休止或延音续音前。三连音暂不支持嵌套及独立时值。无升降音、自动移调、音频试听或反复记号；重复乐段请复制粘贴。

共用时值分组 `{…}-` 将组内每个音的时值减半，`{…}--` 减为四分之一，分组本身不额外占拍。可包含和弦、休止、三连音和装饰音，最多嵌套四层。组内已有时值也一起缩放，例如 `{1 2-}--` 等价于 `1-- 2---`。分组不能跨小节，原来的逐音写法仍然可用。

装饰音占原音符时值，不推迟后续音。倚音的第一音在原拍点开始，主音在最后一个倚音之后开始；不提前到前一拍，也不会移动其他声部。主音可为单音或和弦，三连音内也支持倚音；同一主音不混用倚音、波浪音或琶音。点按模式中装饰音排不进原时值会阻止导出，跨小节延音也不扩大装饰音的容纳时间。

按住模式中倚音和波浪音简化为主音，琶音只保留最后一音，保持原时值，忽略装饰音间隔。按住模式中重叠使用同一键会报冲突；相邻同音会先松开再按下，延音则一直保持。

谱面是输入的实时可视化：高低八度圆点、短音下划线、延长线、和弦、三连音、小字倚音、装饰标记、淡化延音及弧线。4/4 等单拍子按每拍连接短音下划线，例如两个八分音符共用一条线、四个十六分音符共用两条线；混合时值按层连接。休止、拍界及不同三连音组之间断开；6/8、9/8、12/8 按附点四分音符分组。谱面按小节自动换行。暂不提供出版级排版或 PDF 导出。

项目保存包含曲谱、声部、速度表、特殊小节、键位和默认装饰间隔。浏览器自动保存当前草稿；请同时下载 `.score.json` 备份，浏览器本地存储的可用性与保留策略取决于浏览器。
